# Plano de Testes de Software

<span style="color:red">Pré-requisitos: <a href="2-Especificação do Projeto.md"> Especificação do Projeto</a></span>, <a href="3-Projeto de Interface.md"> Projeto de Interface</a>

Os requisitos para realização dos testes de software são:

- Site publicado na internet;
- Navegador da internet: Chrome, Firefox ou Edge.

Os testes funcionais a serem realizados na aplicação são descritos a seguir.

| Caso de teste                                                               | Requisitos associados                                                                                                                                                                        | Objetivo do teste                                                                        | Passos                                                                                                                                                                                                           | Critérios de êxito                                                                        |
| --------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| CT-01: Verificar o cadastro de usuários                                     | RF-01: A aplicação deve permitir que o usuário cadastre uma conta como cliente ou prestador de serviço.                                                                                                                           | Verificar se o cadastro está sendo feito corretamente.                                   | 1. Navegar para a página de cadastro.<br>2. Preencher os campos obrigatórios (nome, e-mail, senha).<br>3.	Selecionar tipo de conta (cliente/prestador).<br>4.	Submeter o formulário.                                              | O usuário deve ser cadastrado com sucesso e uma mensagem de confirmação deve ser exibida. |
| CT-02: Verificar o login de usuários                                        | RF-02: A aplicação deve permitir que o usuário faça login na sua conta.                                                                                                                    | Verificar se o login está sendo feito corretamente.                                      | 1.	Acessar a página de login.<br>2.	Inserir e-mail e senha corretos.<br>3. Clicar em "Entrar".                                                                | 	O sistema deve permitir o login e redirecionar para o painel do usuário.               |
| CT-03: Busca e Visualização de Prestadores de Serviço                  | RF-03: A aplicação deve permitir que o cliente busque e visualize prestadores de serviços disponíveis.                                                                                                        | Testar a busca por prestadores de serviços e exibição dos resultados.                          | 1.	Acessar a tela de busca de prestadores.<br>2.	Inserir critérios de busca (especialidade, localização).<br>3.	Submeter e visualizar resultados.                                                                                                                       | 	O sistema deve exibir prestadores que correspondem aos critérios.                                   |
| CT-04: : Agendamento de Serviços                         | RF-04: A aplicação deve permitir que o cliente agende serviços com os prestadores selecionados.                                                                                                                | Testar a funcionalidade de agendamento de serviços.                                 | 1. Selecionar um prestador de serviços.<br>2.Escolher uma data e hora disponíveis.<br>3. Confirmar o agendamento.<br>                                                                                 | O agendamento deve ser registrado e confirmado com sucesso.                                      |
| CT-05: Verificar a realização de pagamentos online                             | RF-05:A aplicação deve permitir que o cliente realize o pagamento dos serviços de forma online. | Verificar o processo de pagamento online.                     | 1. Após agendar um serviço, proceder para a tela de pagamento.<br>2. Escolher um método de pagamento (cartão de crédito, débito, etc.).<br>3. Inserir informações de pagamento.<br>4. Confirmar o pagamento.                                                | O pagamento deve ser processado com sucesso.                                    |
| CT-06: Visualização do Status de Serviço Agendado                                          | RF-06: A aplicação deve permitir que o cliente visualize o status de um serviço agendado.                                                                                                             | Testar a funcionalidade de visualização de status de serviço.                                  | 1. Após o agendamento, acessar o painel de status de serviços.<br>2. Verificar o status do serviço (pendente, em andamento, concluído).<br>                                                                                  | O status do serviço deve ser atualizado corretamente conforme a progressão.                                         |
| CT-07: Organização e Visualização de Demandas pelo Prestador                     | RF-07: A aplicação deve permitir que o prestador de serviço organize e visualize suas demandas e horários agendados.                                                                                                          | Verificar se o prestador consegue visualizar e organizar seus horários e demandas.                                   | 1. O prestador acessa o painel de agendamentos.<br>2. Visualiza a lista de serviços agendados.<br>3. Reorganiza ou edita horários conforme necessário.                                                                       | O prestador deve conseguir visualizar todos os agendamentos.                                      |
| CT-08: Avaliação de Serviços e Prestadores                       | RF-08: A aplicação deve permitir que o cliente avalie o serviço e o prestador após a conclusão do trabalho.                                                                                                              | Verificar se o cliente consegue avaliar o serviço prestado após sua conclusão.                                    | 1. Após a conclusão de um serviço, acessar a funcionalidade de avaliação.<br>2.	Inserir uma avaliação (nota e comentário).<br>3.	Submeter a avaliação.                                    |A avaliação deve ser salva e exibida corretamente.                                              |
| CT-09: Filtragem de Prestadores de Serviço                         | RF-09: A aplicação deve permitir que o cliente filtre prestadores de serviço por especialidade e localização.                                                                                                                               |Testar a funcionalidade de filtragem por especialidade e localização.                          | 1.	Acessar a funcionalidade de busca com filtros.<br>2.	Inserir parâmetros de filtro (especialidade, distância).<br>3.	Submeter a busca.                                   | O sistema deve retornar prestadores que correspondem aos critérios definidos.                                       |
| CT-10: Comunicação via Chat                | RF-10: A aplicação deve permitir que o cliente e o prestador de serviço mantenham uma comunicação direta através de um chat integrado.                                                                                  | Testar a comunicação entre cliente e prestador via chat integrado.                           | 1.	O cliente acessa a funcionalidade de chat.<br>2. Inicia uma conversa com o prestador.<br>3.	Envia e recebe mensagens.                                                                    | As mensagens devem ser entregues em tempo real.                        |
| CT-11: Edição de Perfil do Prestador  | RF-11: A aplicação deve permitir que o prestador de serviço edite seu perfil e detalhes dos serviços oferecidos.                                                                                           | Verificar se o prestador consegue editar seu perfil e serviços.     |1. O prestador acessa a área de edição de perfil.<br>2. Modifica dados pessoais e detalhes dos serviços oferecidos.<br>3. Salva as alterações. |O perfil do prestador deve ser atualizado corretamente.                                  |
| CT-12: Uso de Cupons Promocionais   | RF-12: A aplicação deve permitir o uso de cupons promocionais e descontos em serviços selecionados.                                                                                                                | Testar a aplicação de cupons de desconto em serviços selecionados. |1.	Inserir um cupom promocional durante o processo de pagamento.<br>2.	Validar o cupom.<br>3.	Confirmar o desconto aplicado.                           | O sistema deve aceitar cupons válidos e aplicar o desconto correspondente.                                     |
